# Example assessment report

`quality-assessment-example.pdf` is a formatted Standard review of the connected
synthetic quality fixture: 100 sampled rows, 50 columns. It contains saved scores,
protected issue references, column profiles, output-only corrections and execution
evidence. It does not contain source record IDs or raw personal values.

The sample illustrates the PDF layout; the application exports the selected run
with its own dataset/date/run filename. See [export verification](../report-exports.md).
